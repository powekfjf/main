这个项目是基于江协科技的STM32教程软件驱动0.96寸OLED显示屏改制而来，采用硬件驱动I2C实现通信，软件驱动的引脚一样，不用更改引脚，用户在使用之前需要属性HAL库，因为这个程序是使用ST公司提供的HAL库的函数代码来编写的，此外我还专门为大家提供了中文显示函数，
以及一部分中文字模，如果用户想要显示其他中文可以在网上下一个取模软件，将字模数据写进Hardware文件中的chonese.h文件里面的二维数组就行了，然后根据需要定义一个数组，里面数据填写需要显示的中文数组下标，然后将数组首地址传入函数就行了。此外我还提供了
16x16和32x32的爱心字模，用户只需要调用函数传入在哪个位置显示就行了。
